# HW3 CRUD upgrade

This is your HW2 project upgraded to HW3 with routers, controllers, services, and error handling.

## Routes
- GET /contacts
- GET /contacts/:contactId
- POST /contacts
- PATCH /contacts/:contactId
- DELETE /contacts/:contactId

## Env
Copy `.env.example` to `.env` and fill:
- MONGODB_USER
- MONGODB_PASSWORD
- MONGODB_URL
- MONGODB_DB
- PORT (optional)

## Run
```bash
npm i
npm run dev
# or
npm start
```
